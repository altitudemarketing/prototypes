Install it in Outlook

Not sure which version you have? If you see a File tab at the top left, you're on classic Outlook. If you see a New Outlook toggle at the top right, you're on the new Outlook.

  1. Click Copy signature above.
  2. In Outlook, open Settings (the gear icon), then Accounts → Signatures.
  3. Create a new signature, name it, and paste with Ctrl + V (Cmd + V on a Mac).
  4. Choose it as the default for new messages and for replies and forwards, then save.
  5. Send yourself a test email to check it.
  1. Click Download file for classic Outlook above and save it.
  2. Rename the file so it ends in .htm instead of .html. Outlook only recognizes .htm signature files.
  3. Close Outlook. Press Windows + R, enter %APPDATA%\Microsoft\Signatures, and press Enter.
  4. Move the renamed file into that folder.
  5. Reopen Outlook and go to File → Options → Mail → Signatures. Select the signature and set it as the default for new messages and replies/forwards.

Alternatively, click Copy signature and paste it into the classic signature editor (File → Options → Mail → Signatures → New). This works too, but Outlook sometimes adjusts the spacing.
