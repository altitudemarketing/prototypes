Current sidebar state

Initial state — no product type selected. Only the five global (Tier 1) filters are shown: Product Type, Frequency, Gender, Mounting, Accepts Pin Diameter, plus the collapsed Advanced Specs drawer. All 50+ category-specific attributes stay hidden.

How conditional reveal works

  • Tier 1 — Global: filters with broad catalog coverage (Frequency 693, Gender 725, Mounting 458, Pin Dia. 285 products). Always visible.
  • Tier 2 — Category options: revealed by the Product Type selection, animated in under a black banner (maps to flowchart groups A+ through G+).
  • Tier 3 — Advanced Specs: ~30 long-tail engineering attributes in a collapsed drawer; groups with zero coverage in the result set are dropped.

Behavior rules (from UI_Filter_Rules)

  • Zero-match terms grey out — never removed — so users see what exists.
  • Counts shown beside every term.
  • Search never resets active filters.
  • One Rear Thd group only (fixes duplicate in Figma).
  • Long term lists truncate to 8 with + show more.
